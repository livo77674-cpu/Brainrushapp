# Brain Rush — Тренажёр устного счёта (Android / RuStore)

**Brain Rush** — полностью автономное (100% Offline) Android-приложение для тренировки устного счёта, концентрации и скорости реакции, созданное на базе **Kotlin**, **Jetpack Compose**, **Material 3**, **Clean Architecture** и **Preferences DataStore**.

## Как получить APK за 3 минуты через GitHub Actions
1. Распакуйте этот архив и загрузите все файлы (включая скрытую папку `.github`) в новый репозиторий на GitHub.
2. Откройте вкладку **Actions** -> **Brain Rush Android CI/CD** -> **Run workflow**.
3. Скачайте готовый `BrainRush-Debug-APK` из раздела **Artifacts**.
